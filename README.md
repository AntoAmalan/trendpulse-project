# TrendPulse - YouTube Trending Video Analytics

TrendPulse is a comprehensive data analysis project examining YouTube trending video metrics across global datasets. This repository is structured into four core phases, covering programmatic data preparation, exploratory data analysis, relational database migration, SQL querying, and executive spreadsheet reporting.
